# zekini.co.za — crawl policy
#
# This file is the only crawl policy this site has. Fleet standard:
# https://github.com/zekini-com/standards/blob/main/docs/crawler-policy.md
#
# It exists because without it the host served the entire homepage at
# /robots.txt with a 200 — there was no such asset, so the request fell through
# to index.html and a crawler asking for robots got HTML.
#
# AI crawlers are deliberately ALLOWED. This is a marketing site whose entire
# purpose is to be found, quoted and explained to someone who has never heard of
# us; the crawlers that feed AI answers are a distribution channel, not a threat.
# There is nothing proprietary in the prose. Ordinary search indexing is a
# separate signal and is unaffected by this either way.
#
# Cloudflare's Managed robots.txt is OFF for this zone (turned off 2026-08-03,
# verified by fetching this URL). While it was on, the live response opened with
# an inherited block that disallowed nine AI crawlers and published a
# `Content-Signal: ai-train=no` express reservation of rights under Article 4 of
# EU Directive 2019/790 — none of which anyone had decided.
#
# If that block ever reappears above this text, the zone setting has been turned
# back on. Fix the zone, not this file: two `User-agent: *` groups is malformed,
# and a strict parser reads the first one and never reaches this.

User-agent: *
Allow: /

Sitemap: https://zekini.co.za/sitemap.xml
